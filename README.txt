MANTRA - POSTER PAGE TURN UPDATE

This package preserves the original MANTRA flow and phone implementation while updating the poster stage to use StPageFlip (PageFlip) from jsDelivr CDN.

Flow: intro video -> poster flip -> manifesto -> vintage phone.

For testing, open index.html in a browser. The StPageFlip library is loaded from a CDN, so internet access is required for the realistic page-turn effect. The original files that were edited are preserved in BACKUP/.

The poster flip uses the original poster image, book-style page curl/shadow rendering, mouse/touch page interaction, and a subtle synthesized paper sound. The phone keypad and phone-related code are otherwise preserved.
